1. **3 秒內看懂**：HQ 是「台北的商業空間設計＋施工，一份合約、一位 PM」。
2. **30 秒內相信**：看到真實作品、客戶 logo、數字、流程。
3. **1 個明確下一步**：聯絡 PM（本地用表單／電話，國外加 WhatsApp）。

兩種訪客：

- **業主**：本地企業、外商在台分公司、飯店、品牌門市。
- **海外設計師／PM**：要找台灣有執照的施工夥伴。

## 4. Hero 方案（✅ 2026-11-20 Christian 選定 H2 全版照片）

| 方案                    | 長相                                                   | 優點                                             | 缺點                     |
| ----------------------- | ------------------------------------------------------ | ------------------------------------------------ | ------------------------ |
| **H1 左字右圖**（建議） | 淺灰底；左邊大標題＋按鈕，右邊一張圓角 24 的實景大照片 | 照片看得清楚、字也清楚；最像 Figma 的 Light 主題 | 比全版照片少一點氣勢     |
| H2 全版照片             | 跟現在一樣，但遮罩變淡、字放左下                       | 氣勢最強                                         | 字壓在照片上，對比難控制 |
| H3 深藍 Mesh            | 深藍漸層背景（Figma Background/Mesh）＋ 小張作品輪播   | 最有「品牌感」                                   | 首屏看不到真實空間       |

**定案：H2 全版照片。** 以下是 H2 的做法，重點是「氣勢要有，字也要看得清楚」。

| 項目     | 做法                                                                                                                           |
| -------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 高度     | 桌機約 88vh（留一點縫讓人知道下面還有內容）；最低 640px                                                                        |
| 照片     | 一張實景，用 `<img>` + `fetchpriority="high"` + `preload` 載入，webp，約 2400px 寬；`object-fit: cover`。**不再用 CSS 背景圖** |
| 遮罩     | 不再整片壓暗。改成「左下深、右上透明」的漸層：`#101924` 從 70% → 0%。照片右半邊幾乎原色                                        |
| 文字位置 | 左下角，最寬 640px；label → 大標題 → 一句說明 → 2 顆按鈕                                                                       |
| 文字顏色 | 白字；次要文字白 80%                                                                                                           |
| 按鈕     | 主要：橘底 `#ff4e2a` + 深字 `#101924`；次要：白色外框膠囊                                                                      |
| 數字條   | 放在照片**下方**的白底橫條，不壓在照片上（數字直接寫在 HTML，不跳動）                                                          |
| 對比檢查 | 字的區域實測對比 ≥ 4.5:1；換照片時要重測                                                                                       |
| 照片選擇 | 左下要比較暗、比較乾淨（沒有雜亂細節），右上放空間亮點。**需要你挑 2–3 張候選**                                                |
| 導覽列   | 在照片上時是透明＋白字；往下捲變白底＋深字                                                                                     |

**H2 的風險與對策**

- 字壓在照片上 → 用漸層遮罩＋固定放左下，並在驗收時量對比。
- 照片太大拖慢首屏 → webp、`srcset` 給手機小圖、`preload`。目標 LCP < 2.5 秒。
- 每次換照片可能看不清 → 在 CSS 留一個「遮罩強度」變數，換圖時只調一個數字。

## 5. 視覺規則（從 Figma 搬過來）

- 底色：白 `#ffffff` 與淺灰 `#f5f5f5` 交替；深色只有「Hero 照片」和「最後的 CTA 深藍區塊」頭尾兩處。
- 文字：主色 `#101924`、次要 `#0a0a0ab2`。
- **橘色 `#ff4e2a` 只給「最重要的那顆按鈕」**，按鈕上的字用深色 `#101924`。橘色文字改用 `#cc3e22`。
- 字體：英文 Satoshi、中文 Noto Sans TC。
- 圓角：按鈕 999（膠囊）、卡片 16、照片 24。
- 卡片風格：Flat（不用毛玻璃）。
- 動畫：只做「捲到時淡入往上 12px」，0.4 秒；數字不跳動。有「減少動態」設定的人完全不動。

- og:image 改成首頁 Hero 照片（1200×630）。

1. 一張實景大照片當 Hero，不用影片。
