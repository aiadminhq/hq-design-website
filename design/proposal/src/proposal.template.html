A-00Thesis · 設計論點

一套會動的施工圖說。

惠強不是把 AI 當渲染工具的設計公司，而是把三十年工法資料接進整條流程的施工方。所以官網不用行銷網站的版面。首頁沿用 Powerhouse 的互動骨架（影像場、捲動縮放、點圖放大成 hero），其餘全部用施工圖說自己的慣例當介面：圖名框是導航、尺寸線是圖說、圖層是解釋 BIM 的方式、對照 wipe 是誠實標示的展示。影像是版面上唯一的顏色，動態是「把圖畫出來」的動作。品牌 pattern 與受控的 HQ Mesh 漸層只在少數大面積出現。

01 · Drawing conventions as UI

製圖慣例就是介面

業主每天在看施工圖：圖名框、尺寸線、圖例、圖層、版次。這些不是裝飾，是大家已經會讀的介面語言。網站直接借用，不必再教。

02 · Image is the colour

影像是唯一的顏色

白／冷灰／深藍承載結構，橘紅只在決策點與 60° tick 出現，單頁佔比 ≤10%。HQ Mesh 漸層限四組配對、只作大面積底層。3:2 影像走 9／6／4 欄，每張由 prov 推導標示。

03 · One pen

一支筆的動態

全站只有一種動勢：一條 60° 的線在畫。它是尺寸線的 tick、流程軸的進度、路由轉場的斜切幕、圖紙索引的目前位置。一個母題，四個工作。

Device 01
圖名框 Title block固定在右下角的常駐 chrome：圖號、圖名、版次、語言、頁碼。捲動時同步，等於麵包屑、進度與語言切換三合一。手機上貼底、拇指可及，兼作選單入口。
本頁右下角即為實作示範，全頁即時同步。
Device 02
尺寸線 Dimension string每張影像下方不放「圖說」，放一條尺寸線：兩端 60° tick，線上標註真實數據（5,940 SQM · 1,797 坪），右端接來源標示。tick 是品牌 slash，數字是可稽核事實，一個元件同時完成三件事。
首頁拼貼、實績卡、案例 hero、模型空間圖片全部沿用。
Device 03
圖層 Layers用 BIM 自己的概念解釋 BIM：建築、機電、家具、施工分區四個可開關的圖層。同時打開建築與機電時，衝突點被標出——「撞管在模型裡被找到，不在工地」一句話變成一個畫面。
模型空間章節可操作示範。
Device 04
對照 wipe Intent ↔ As-built把內容政策紅線變成賣點：同一空間的設計圖面與完工實景（或提案視覺）並列，60° 斜邊 wipe 拖曳對照，兩側各自保留來源標示。誠實不是免責聲明，是可以互動的證據。
案例頁示範。需要內容層加配對欄位（見裁決 D3）。
Device 05
圖紙索引 Sheet rail桌機左緣一條直排的圖紙索引，圖號拉丁字橫躺、中文直立，像圖冊裝訂邊。捲動同步、可點擊跳轉。手機收進圖名框。
本頁左緣（≥1180px）即為示範。
Device 06
座標讀數 Model space沉浸深底的 AI 章節是「模型空間」：十字游標、右上角跟隨游標的 X／Y 座標（mm）、受控的 navy→cool gray mesh 加 6% grain。給設計師會心一笑，給業主一種「這是工具不是廣告」的感覺。
模型空間章節平面圖上移動游標。
A-01Colour · 色彩、比例與受控漸層

白紙、墨線、一條橘紅；漸層只有四組配對。

全部引用 Token 3.0，此提案不新增任何色碼。深色主題由 token 自動切換。漸層依你的裁示開放，但只用 CIS §3.4 的 HQ Mesh 四組配對加 3–8% grain，做大面積底層；漸層文字、玻璃擬態、霓虹仍不用。

A-02Typography · 字體與階層

Satoshi 300 對 Noto Sans TC 700，數字一律 Geist Mono。

Satoshi 以 Variable 原檔自架（300–900，不 subset、不轉檔）。原創之處在對比：英文 statement 用 300 細體，中文用 700 粗體，像圖紙上的英文標註對中文圖名。標題裡的「×」改成品牌 60° slash 字形。直排只用於圖紙索引與圖名框，像圖冊裝訂邊。

A-0460° system · 品牌 pattern 與介面用法

Figma 的品牌 pattern，加一條 60° 的線做六件事。

右側四格是 Figma 檔 HQ Background Pattern-1（node 1073-100220）的原始向量，重上色為 currentColor 後可在任何底色上用：深藍底白線、紙白底深藍線、極淡底當空狀態。原始的橘底版只留給 OG 與封面等小面積，網站頁面不用滿版橘。介面上的 slash 一律是 1px 線旋轉 60°，端點平切，永不圓角。

A-05Motion · 動態原則與 token

一支筆。對位，不彈跳。

Motion for React 是唯一動畫引擎，GSAP 不進第一版。所有 transition 取自 hqMotion token（沿用 Codex 已寫好的 lib/motion.ts），MotionConfig reducedMotion="user" 統一處理減少動態：transform 全部關閉，只留 opacity 交叉淡化，捲動拼貼退成靜態網格，尺寸線直接顯示。

  • 一支筆：所有動態都是「一條 60° 線在畫」。尺寸線 tick、流程進度、路由斜切幕、圖紙索引標記共用同一個母題與同一組 token。
  • 影像用「裁切」揭露，不用縮放模糊。clip-path inset 自 3:2 框內展開，像圖紙上的裁切線。
  • 線先畫，字再進。尺寸線 scaleX 0→1，標註與案名再以 0.1s stagger 進場。
  • Scroll 只驅動 transform 與 opacity。useScroll + useTransform 走 MotionValue，不觸發 React re-render。
  • 轉場失敗仍可到達路由。共享元素轉場是加分，不是前提；沒有 sourceRect 就直接淡入 hero。

A-14Revision · v0.1 → v0.2 變更與理由

參考只是參考。這一版把借來的換成自己的。

v0.1 在結構上仍是「現有靜態站的排版 + Powerhouse 的拼貼」。v0.2 逐項換成從惠強施工圖說慣例長出來的裝置，每一項都有實用理由，不是為了不同而不同。

項目v0.1v0.2為什麼
常駐 chrome頁首 sticky bar 含語言切換頁首只留 lockup、選單、一個 CTA；新增右下角圖名框承載圖號、圖名、版次、語言、頁碼麵包屑、進度、語言三合一；手機拇指可及；業主看圖名框不用學
圖說影像下方文字 caption + 來源標示尺寸線：60° tick、線上真實數據、右端來源標示一個元件同時是品牌 slash、可稽核事實與標示；hover 畫線是自然的動態
解釋 AI／BIM滑桿 + 等角圖滑桿 + 四個圖層開關 + 衝突標記 + 座標讀數 + 模型空間 mesh「撞管在模型裡被找到」從口號變成可操作的畫面
誠實標示標示與影像性質區塊加上設計意圖 ↔ 完工實景的 60° wipe 對照把紅線變賣點：回答「蓋出來會不會一樣」
品牌 pattern手繪的 51/12/63 線條系統Figma 1073-100220 原始向量，重上色為 currentColor 四種用法用品牌自己的圖紋，不重畫
漸層全面禁止開放 HQ Mesh 四組配對 + 3–8% grain，只作大面積底層你的裁示；CIS §3.4 本來就允許受控漸層
桌機導航無左緣直排圖紙索引，捲動同步長頁有座標；直排是台灣圖冊裝訂邊的語言
Display 字體Satoshi 700 + ×Satoshi 300 對 700，× 改 60° slash 字形細粗對比像英文標註對中文圖名；品牌角度進入標題
實績 filterchips + search圖例 legend + 找圖；兩帶命名為竣工圖集／設計圖集用圖說的詞，不用 SaaS 的詞
Codex 元件未評估逐一判定沿用／改寫／不搬（A-13）不重做已經對的東西
驗收七道閘門七道閘門 + 五項效能預算實用性要有數字
