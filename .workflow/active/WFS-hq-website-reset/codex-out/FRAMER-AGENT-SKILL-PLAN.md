# Framer Agent 協作技能規劃

日期：2026-09-03  
作用頁面：`/hq-home`  
目前狀態：規劃完成；指令已填入 Framer Agent，但尚未送出，也未修改或發佈畫布。

## 協作分工

| 工作角色 | 主責 | 不得越界 |
|---|---|---|
| Framer Agent | 原生畫布的 breakpoint、Stack、Grid、文字層級與元件調整建議 | 不自行 Publish、不刪頁、不把來源未確認圖片宣稱為 HQ 實績 |
| Codex + Framer MCP | 精確 node 修改、品牌規格檢查、修改前後 read-back、變更紀錄 | 不繞過素材授權與內容裁決 |
| 人工審核 | 攝影授權、案例真實性、品牌內容與正式發佈 | 未確認前不得以技術成功取代內容核可 |

## 建議建立的六項 Framer 工作技能

1. **Responsive Layout Audit**：逐一檢查 Desktop、Tablet、Phone 的溢位、文字折行、CTA、統計數據與導覽可用性。
2. **Hero Art Direction**：控制 3:2 主視覺、約 88vh 高度、文字安全區、overlay 對比與裁切焦點；來源未確認圖片只作內部版面測試。
3. **Brand Token Alignment**：將顏色、間距、圓角與動態收斂至 HQ 規格；`#D64518` 僅作 5–10% 強調。
4. **Component Cleanup**：整理 Nav、CTA、Project Card、Service Card、Footer 的共用元件與狀態，避免逐頁漂移。
5. **Template Residue Sweep**：移除 Archiste 聯絡資訊、作者 credit、Blog/Journal 殘留與不屬於 HQ 的連結；正式刪除前保留清單與回復方式。
6. **QA Read-back**：每批變更後讀回節點、檢查三個 breakpoint，並分開記錄「已修改、可預覽、內容已核可、已發佈」四種狀態。

## 可立即執行的工作順序

1. 取得 Framer Agent 的只讀診斷表，不讓 Agent 自行修改。
2. 先修 Hero 高度、裁切、文字對比與手機溢位；暫不換入 NAS 實拍。
3. 修正 `31 Years` 與 `EST. 1995 / 30+` 的內容不一致，需先採用公司簡介的權威值。
4. 清理 Footer 與 template 殘留，但刪除節點前另列精確清單。
5. 攝影授權清除後，再以正式 HQ 實拍取代 Hero 與 Selected Work 圖片。

## 驗收門檻

- 三個 breakpoint 均無水平溢位，Hero 文字與 CTA 可讀。
- Hero 不超過約 88vh，裁切不破壞空間垂直線與主要構圖。
- 品牌橘面積不超過 10%，不使用 neon、glassmorphism、過度圓角或浮誇動態。
- 任何 Hero／案例圖片均可追溯來源、類型與授權狀態。
- 未執行 Publish；正式上線需獨立人工確認。
