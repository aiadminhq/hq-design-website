06施工圖說 · Construction Documentation

完工時你手上會有什麼？

你收到的不只是完工，是可稽核的一整套文件：竣工圖、操作手冊、保固書、驗收文件。

Construction Documentation — six steps from technical detailing to handover; what you receive at each step.

Input · 你提供整合後的 BIM 模型與衝突解決結論、材料選樣的最終決定、關鍵區域的樣板確認。
Output · 你拿到施工圖說全套（平面、立面、剖面、大樣、工序）、樣板確認紀錄；完工後取得竣工圖、操作手冊、保固書與驗收文件。
Stage06 / 07
Q業主的問題

「這疊圖跟我有什麼關係？完工後我拿到的是什麼？」

惠強室內裝修（HQ Design）在施工圖說階段依六個步驟深化：技術詳圖、施工文件、材料協調、樣板確認、現場品管、竣工交付。業主最終收到四類文件：竣工圖、操作手冊、保固書與驗收文件。

施工圖說是現場執行的依據：節點、收邊、材料接合與施工順序在圖上定案，關鍵區域先做實體樣板確認再施作。

Six steps — technical detailing, construction documentation, material coordination, mock-up verification, site quality control and handover documentation — each with a deliverable you receive.

06How · 我們怎麼做

施工深化六步，各步你會拿到什麼？

06.1
Steps 01–02

技術詳圖與施工文件

節點、收邊、材料接合與施工順序圖說；平面、立面、剖面、大樣與工序文件——現場執行的依據。

依據公司簡介施工深化六步之 01 Technical Detailing、02 Construction Documentation。
06.2
Steps 03–04

材料協調與樣板確認

材料選樣、供應商確認與交期管控；關鍵區域製作實體樣板，由你在現場確認後才施作。

依據六步之 03 Material Coordination、04 Mock-up Verification：「關鍵區域實體樣板製作與確認」。
06.3
Steps 05–06

現場品管與竣工交付

品質查核、進度追蹤與安全管理紀錄；完工時交付竣工圖、操作手冊、保固書與驗收文件。

依據六步之 05 Site Quality Control、06 Handover Documentation；最終文件 4 類。
06Why it matters · 對業主的意義

施工圖說對業主的意義是什麼？

Auditable Set

可稽核的一整套文件

竣工圖、操作手冊、保固書與驗收文件，營運與後續維護有據可查。

Mock-up First

樣板先確認再施作

關鍵區域以實體樣板確認，減少完工後的認知落差。

Site Reference

圖說即現場執行依據

節點、收邊與工序在圖上定案，現場不憑口頭。
